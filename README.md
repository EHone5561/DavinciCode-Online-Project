# 다빈치 코드 (Davinci Code) — 사용 안내서

2~4명이 함께 즐기는 **다빈치 코드 보드게임**입니다.
컴퓨터(CPU)와 혼자 연습할 수도 있고, 같은 네트워크에 있는 친구와 함께 할 수도 있습니다.
**플레이는 웹 브라우저에서 마우스로** 합니다.

**파이썬 설치가 필요 없습니다.** `dist\다빈치코드_웹.exe` 하나만 있으면 됩니다.

## 1. 실행하기

`dist\다빈치코드_웹.exe` 를 **더블클릭**하면 아래 메뉴가 뜹니다.

```
====================================================
   다빈치 코드 (Davinci Code) — 웹 버전
   브라우저에서 마우스로 플레이합니다.
====================================================
   [1] 혼자 해보기    (CPU와 연습 — 바로 시작)
   [2] 방 만들기      (내가 방장 — 참가자 기다림)
   [3] 참가하기       (방 주소로 접속)
   [0] 종료
----------------------------------------------------
선택 [1/2/3/0] :
```

번호를 고르면 잠시 뒤 **브라우저가 자동으로 열립니다.**

> 첫 실행 시 Windows 방화벽 창이 뜨면 **[2] 방 만들기**를 쓸 때만 **"개인 네트워크"에 허용**을 눌러주세요.
> (친구가 접속하려면 필요합니다. 한 번만 허용하면 다음부터 안 뜹니다.)

---

## 2. 혼자 해보기 ([1])

가장 간단합니다. 규칙을 익힐 때 쓰세요.

1. `[1]` 입력
2. **인원** — 2~4 (Enter=2)
3. **브라우저 포트** — Enter(8000)로 두면 됩니다.
4. 브라우저가 열리고, 나머지 자리는 CPU가 자동으로 플레이합니다.

---

## 3. 같이 하기 ([2] 방장 + [3] 참가)

### 방장 (방을 여는 사람)

1. `[2]` 입력
2. **인원** — 2~4명 (Enter=2)
3. **CPU 좌석 수** — 부족한 자리를 CPU로 채웁니다.
   - 예) 친구 1명과 하려면 인원 2, CPU 0
   - 예) 혼자 3인전을 구경하며 하려면 인원 3, CPU 2
4. **브라우저 포트** — Enter(8000)
5. 화면에 **참가자에게 알려줄 주소**가 뜹니다.

```
====================================================
   참가자에게 알려줄 주소
     http://192.168.0.10:8000/
   (같은 네트워크 안에서만 접속됩니다)
====================================================
```

이 주소를 친구에게 그대로 알려주세요.

### 참가자 (접속하는 사람)

1. `[3]` 입력
2. **방 주소** — 방장이 알려준 주소 입력 (예: `192.168.0.10`)
   - 잘못 입력하면 다시 물어봅니다.
3. **게임 포트** — Enter(8765)
4. **브라우저 포트** — Enter(8000)
5. 브라우저가 열리면 **이름을 입력**하고 시작합니다.

방장을 포함해 인원이 다 모이면 게임이 시작됩니다.

---

## 4. 화면 보는 법

브라우저 화면은 이렇게 구성됩니다.

```
┌─────────────────────────────────────────────┐
│  상단: 라운드 · 덱 장수 · 현재 차례          │
│  ┌─────────┐                    ┌─────────┐ │
│  │ 상대 1  │   ┌──────────┐     │ 상대 3  │ │
│  │ (카드)  │   │  패산    │     │ (카드)  │ │
│  └─────────┘   │ (가운데) │     └─────────┘ │
│                └──────────┘                 │
│                 ┌─────────┐                 │
│                 │ 상대 2  │                 │
│                 └─────────┘                 │
│                                             │
│              내 패 (맨 아래)                │
│         [값 버튼들]  [채팅 입력창]          │
└─────────────────────────────────────────────┘
```

- **하단 = 나** (내 카드는 값이 전부 보임)
- **상대 카드는 ■(검정) / □(흰색)** 으로만 보입니다. 값은 비밀이에요.
- 공개된 카드는 **파란 띠**로 표시됩니다.
- 맨 아래 **hint 줄**: `하단=나 · 상대 카드를 클릭해 지목 · 값은 하단 버튼에서 선택`

---

## 5. 게임 진행 (마우스 조작)

게임 입력은 전부 **버튼/클릭**이고, 맨 아래 **텍스트 입력창은 채팅 전용**입니다.

### 내 차례일 때 — 상대 카드 지목

1. 지목할 **상대의 카드를 클릭** (카드에 테두리가 켜집니다)
2. 맞다고 생각하는 **값 버튼을 클릭** → 자동으로 전송됩니다.

> 순서: 상대 카드 클릭 → 값 버튼 클릭 (두 번이면 끝)

### 조커를 뽑았을 때

- **조커 삽입**: 카드 사이에 나타나는 **▶ 화살표**를 클릭해 위치를 고릅니다.
- **조커 옆에 놓기**: **[앞] / [뒤] 버튼**으로 방향을 고릅니다.

### 검은 카드 장수 고르기

게임 시작 때 나눠받을 **검은 카드 수**를 아래 버튼(`0 1 2 3 4`)으로 고릅니다.

### 덱이 비었을 때 (오답 벌칙)

**공개할 카드를 고르세요** — 내 카드가 실제 카드 모양 버튼으로 나오면, 깔릴 카드를 클릭합니다.

### 정답/오답 표시

패산 위에 크게 **빨간 ○(정답) / 파란 ✕(오답)** 가 뜹니다.

### 값 표기

| 표기 | 뜻 |
|---|---|
| `0w` ~ `9w` | 흰색 숫자 0~9 |
| `0b` ~ `9b` | 검은색 숫자 0~9 |
| `aw` / `ab` | 흰색 / 검은색 10 |
| `bw` / `bb` | 흰색 / 검은색 11 |
| `Jw` / `Jb` | 흰색 / 검은색 조커 |

## 6. 내 차례가 아닐 때

- 남들이 두는 **화면을 내 시점에서 계속 볼 수 있습니다.**
- 누가 무엇을 공개했는지 **`[공개]` 목록**에 계속 쌓입니다.
- **채팅은 언제든** 칠 수 있습니다 (내 차례와 무관).

### 탈락하면

탈락해도 **관전 화면**이 계속 나옵니다. 상단에 **"관전 중"** 이 뜨고,
다른 사람들의 진행 상황과 공개 카드를 계속 볼 수 있어요.
패배한 사람의 손패는 **전부 공개된 채로** 화면에 남습니다.

---

## 7. 게임이 끝나면

패산 자리에 **🏆 최종 순위**가 뜹니다. 그 아래에 **🔄 다시하기** 버튼이 있어요.

- **다시하기** — 방에 있는 **사람이 전원 누르면** 같은 구성원으로 새 게임이 시작됩니다.
  - 버튼 라벨이 `🔄 다시하기 (2/3)` 처럼 투표 현황을 보여줍니다.
  - 내가 누르면 `✓ 다시하기 (3/3)` 로 바뀌고 비활성됩니다.
  - **CPU 좌석은 항상 유지**됩니다.
  - 2인에서 한 명이 나가면 그 자리는 CPU로 대체됩니다.
  - 3~4인에서 한 명이 나가면 그 사람만 빠지고 좌석이 다시 배치됩니다.

## 8. 자주 있는 상황

### "접속 중..." 에서 멈춰 있어요

- 방장이 `[2]` 로 방을 먼저 열었는지 확인하세요.
- 주소가 방장 화면의 **참가자에게 알려줄 주소**와 같은지 확인하세요.
- 포트(8000 / 8765)가 양쪽 같은지 확인하세요.

### 아무도 지목하지 않아서 게임이 안 끝나요

카드가 공개되지 않으면 게임이 진행되지 않습니다.
**CPU 좌석을 섞으면** 자연스럽게 해결됩니다. (인원 3 + CPU 1 처럼)

### 브라우저를 닫거나 프로그램을 종료하면?

**기권패**로 처리되고, 그 사람의 카드는 전부 공개됩니다. 남은 사람들은 게임을 계속합니다.

### 같은 PC에서 두 명이 하려면?

브라우저 창을 두 개 띄우면 됩니다.
단, **브라우저 포트를 다르게**(예: 방장 8000, 참가자 8001) 지정해야 합니다.

## 9. 친구와 함께 하는 범위

| 상황 | 가능 여부 |
|---|---|
| 같은 PC | 됨 (주소에 Enter) |
| 같은 공유기 / 같은 WiFi | 됨 |
| 다른 집 / LTE / 카페 WiFi | **안 됨** (추가 설정 필요) |

`192.168.x.x` 는 **공유기 안에서만 통하는 주소**라서, 다른 네트워크에서는 접속할 수 없어요.
인터넷 너머로 하려면 **ngrok 같은 터널링**이나 **VPN**이 필요합니다.

## 10. 실행 옵션 (명령줄에서 쓸 때)

명령 프롬프트에서 인자로 바로 실행할 수도 있어요.

```
다빈치코드_웹.exe solo 3                     # 혼자 해보기 (3인)
다빈치코드_웹.exe host 3 --cpu 1             # 방 만들기 (3인, CPU 1)
다빈치코드_웹.exe join 192.168.0.10          # 참가하기
다빈치코드_웹.exe help                       # 도움말
```

| 옵션 | 설명 |
|---|---|
| `solo <인원>` | 혼자 해보기. 인원 2~4 |
| `host <인원>` | 방 만들기 |
| `join <주소>` | 참가하기 |
| `--cpu <수>` | 뒤쪽 좌석부터 CPU로 채움 (host) |
| `--port <포트>` | 게임(relay) 포트 (기본 8765) |
| `--web-port <포트>` | 브라우저 포트 (기본 8000) |
| `--web-host <주소>` | 웹서버 바인딩 (0.0.0.0 = 다른 PC 허용) |
| `--no-browser` | 브라우저 자동 실행 안 함 |

## 11. 터미널(텍스트) 버전 — 간단 안내

웹 대신 **터미널에서 텍스트로** 플레이하는 버전도 있습니다 (`dist\다빈치코드.exe`).
게임 규칙과 진행은 완전히 동일하고, 조작만 키보드 입력입니다.

```
다빈치코드.exe          # 메뉴 (서버 열기 / 참가하기 / 혼자 해보기)
다빈치코드.exe server 3 --cpu 1
다빈치코드.exe client --host 192.168.0.10
다빈치코드.exe demo
```

내 차례가 오면 이렇게 입력합니다.

```
>> 추측: [#] [자리] [값(3b/aw/Jb/Jw)]  q=멈춤 :
```

- `3 2 1b` 처럼 **상대번호 자리 값** 순서로 입력합니다.
- `q` 또는 `그만` 을 넣으면 이번 차례를 넘깁니다.
- 그냥 Enter 를 치면 다시 물어봅니다 (실수 방지).

화면에서는 `□`(흰색 비밀) / `■`(검은색 비밀) / `*`(방금 뽑음) 로 카드가 표시됩니다.
자세한 내용은 이 문서의 앞 절과 동일합니다.
